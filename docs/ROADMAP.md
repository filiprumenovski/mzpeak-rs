# Scope

The supported implementation is the v2-only streaming pipeline described in
README.md. The v1 compatibility stack and broad Python wrapper API are removed.

Open work requires evidence: wider instrument/corpus validation, current
Python/NumPy support, source-specific mobility units and precursor/window
representation, and independent interoperability against the current HUPO-PSI
format. Existing synthetic or single-run results do not establish those claims.
