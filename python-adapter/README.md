# mzPeak integer adapter

Read the study's integer archives through the official mzPeak Python interface.
The package includes the native Rust decoder and installs the pinned official
reader. It needs no RAW reader, vendor runtime, research checkout, or PYTHONPATH.

Requires CPython 3.11–3.13, Git, Rust 1.85 or later, and a C compiler to build
from source. Use a fresh virtual environment: the official reader owns the
`mzpeak` import, so do not install this repository's separate Rust Python
extension in that environment.

```bash
git clone https://github.com/filiprumenovski/mzpeak-rs.git
cd mzpeak-rs
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./python-adapter
python -m mzpeak_compat.example
```

On Windows, activate with `.venv\Scripts\Activate.ps1`. Installation downloads
Python dependencies and Rust crates. The installed example runs without network
access and compares the bundled synthetic archive against its official-format
counterpart. Source installation compiles the decoder once; a built wheel needs
no Rust compiler at runtime.

```python
from mzpeak_compat import MzPeakFile

with MzPeakFile("complete.experimental.zip", filter_profile_zeros=True) as run:
    spectrum = run[0]
    mz, intensity = spectrum["m/z array"], spectrum["intensity array"]
    selected = run.spectra_signal_for_indices([0, 1])
```

The default preserves every stored point. `filter_profile_zeros=True` removes
interior profile zeros as the official exporter does. This mode scans profiles
at open to update metadata counts; it does not keep a signal cache.

This package reads existing integer archives; it does not convert RAW files.
It contains the native decoder tested on Astral, with package-relative imports
and library discovery. The adapter also closes metadata streams explicitly to
release Windows file locks. The archived benchmark source and reports remain frozen.

Values obey the archive's declared error bounds, not bitwise equality. Exact
m/z cutoffs can differ within the quantization band. The pinned official reader
ignores its coordinate-window argument; use the same explicit mask to compare
windows. See the [full adapter validation](../benchmarks/raw-integer-2026-10/ADAPTER_VALIDATION.md)
for supported operations and reference-reader limits.

Run the package tests after installation:

```bash
python -m unittest discover -s python-adapter/tests -v
```

The example files are synthetic, generated by `tools/make_example.py`, and
covered by this repository's licenses. They contain profile and centroid scans,
zero runs, and an empty scan; they contain no experimental or patient data.
